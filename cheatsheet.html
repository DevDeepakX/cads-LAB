Cheat Sheet — S3 Lab

Attack Commands

aws s3 ls — list buckets

aws s3 cp s3://monish-s3-lab/test.txt . — simulate download

get-object s3://... — simulate GetObject

exploit --read-object — simulate exploit

Defense Commands

put-public-access-block — block public access (mitigation)

aws s3api put-public-access-block --bucket monish-s3-lab ... — simulated full command

check-policy monish-s3-lab — verify policy
